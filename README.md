# Сосновый берег

Учебное бронирование загородных домов — тема «Загородные дома» из практического задания 4 (интерактивная карта и живой интерфейс бронирования). Стек: чистый HTML/CSS/ванильный JS с ES-модулями, без npm, React, сборки и сервера.

## Запуск

Сайт статический. В этом окружении он уже раздаётся nginx на http://127.0.0.1/ (root = `/workspace/wd-task4/site`).

Для локального запуска без nginx — любой статический сервер из каталога `site/`, например:

```bash
python3 -m http.server 8080 --directory site
# или
npx serve site
```

Открыть http://localhost:8080.

**Важно:** ES-модули требуют http(s) — открытие `index.html` напрямую через `file://` не сработает.

## Функции

- Схема посёлка с дорогой, озером, деревьями и 8 кнопками-домиками (координаты из `data.js`); два дома изначально заняты.
- Список домов с синхронным выбором: клик по списку выделяет дом на схеме и наоборот.
- Статусы «Свободен / Выбран / Занят» — цвет, маркер и текст, легенда под схемой; занятые дома выбрать нельзя.
- Фильтры по числу гостей и максимальной цене с кнопкой сброса: список и схема обновляются одновременно; выбор сбрасывается, если дом скрыт фильтром; при пустом результате — подсказка.
- Карточка дома с описанием и формой: гости (1..вместимость), ночи (1–30), живой расчёт «цена × ночи», валидация с ошибками у полей.
- Подтверждение брони с номером Б-0001… и защитой от двойного клика.
- Раздел «Мои брони» с отменой: дом снова становится свободным.
- Сохранение броней в localStorage: восстановление при обновлении страницы, чистка повреждённых данных, понятные сообщения при сбоях хранилища.
- Кнопка «Сбросить демо» с подтверждением — очищает только свой ключ хранилища.
- Адаптивная вёрстка (сетка от 900px, стек ниже) и клавиатурная доступность: видимый фокус, aria-pressed, aria-describedby, aria-live.

## Ограничение учебного бронирования

Реальных платежей и сервера нет. Брони хранятся только в localStorage текущего браузера под одним ключом `sosnovy-bereg-demo-v1`. Об этом говорят подписи на странице: «Учебное демо: бронирования сохраняются только в этом браузере» и «Учебное демо, реальная бронь не оформляется».

## Нейросеть и промпты

Сайт выполнен с **Kimi Code CLI** (агентная оркестрация; каждая подзадача выполнялась отдельным кодовым агентом). Промпты, которые помогли:

- «Подготовь рабочую основу сайта бронирования домов: схема посёлка и список строятся по одному массиву из 8 домов с разной ценой и вместимостью, два дома изначально заняты; ES-модули, без сборки».
- «Фильтры по гостям и максимальной цене должны одновременно обновлять список и схему; если фильтр скрыл выбранный дом — сбрось выбор и сообщи об этом».
- «Подтверждение создаёт ровно одну бронь с номером, дубликат при двойном клике не создавай; брони сохраняй в localStorage одним ключом и восстанавливай при обновлении страницы».
